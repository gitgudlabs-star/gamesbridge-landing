What we're building

Built for how friend groups
actually play.

Every feature solves a real problem. No filler.

🔗

Group Library Matching

See every game your entire friend group already owns or has access to. The games everyone has are front and centre. No more "does everyone have it?" in the group chat.

📦

Subscription Aware

Game Pass, PS Plus, EA Play — we know what's covered. If one person in the group has it on subscription, we'll flag it so nobody has to buy anything they don't need to.

🎯

Mood & Vibe Filtering

From your shared library, filter by what you're all in the mood for. Relaxed, intense, competitive, story-driven — narrow it down fast without browsing forever.

⏱️

Session Length

Got a quick hour or a full evening? We filter your shared games by how long they actually take so you only see what fits the night you have.

👥

Multiple Groups

Friday Night Crew, work mates, family — create as many groups as you like. Each one gets its own matched game list based on exactly who's in it.
